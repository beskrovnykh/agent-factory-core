# Журнал дня

Собирает день из **трёх** источников, потому что ни один не знает всей картины:

1. **Сессии фабрики** — расход, ходы, вердикты. Знает только про то, что подняла очередь.
2. **Мержи в `main`** — что реально приехало. Работа прямыми сессиями мимо очереди видна только здесь.
3. **Доска** — что сдвинулось у человека.

Второй источник обязателен: в дни, когда фабрика стоит на потолке, весь результат дня делается мимо неё, и без git журнал покажет пустой день.

## Как запускать

```
python3 core/daily.py                    # сегодня, markdown
python3 core/daily.py 2026-09-15         # конкретный день
python3 core/daily.py 2026-09-15 --json  # сырые числа
```

Файл дня кладётся в `journal/ГГГГ-ММ-ДД.md` и коммитится.

## Правила

**Хост не ответил — сказать словами, а не посчитать нулём.** Пустая строка в сводке не отличима от «ничего не было», и по ней нельзя понять, работает ли фабрика. Сборщик печатает причину.

**Числа не округлять в лучшую сторону и не прятать неудобные.** День, в котором потратили много и сделали мало, — это и есть материал; сглаженный день бесполезен и для блога, и для работы.

**TLDR пишет человек.** Скрипт даёт числа и список, вывод — не его дело.

## Что стоит дописывать руками

- что сломалось и почему это было незаметно;
- какое число оказалось неверным и как это выяснилось;
- сколько задач осталось на человеке к концу дня.
